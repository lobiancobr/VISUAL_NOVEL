# 🎮 VISUAL_NOVEL

Repositório de apoio para o estudo e desenvolvimento de **Visual Novels**, com foco em narrativa interativa, construção de histórias ramificadas e introdução às principais ferramentas utilizadas na área.

O conteúdo foi organizado para que estudantes iniciem seus estudos com o **Twine**, explorando conceitos fundamentais de narrativa não linear, e avancem posteriormente para o **Ren'Py**, uma das engines mais utilizadas na criação de Visual Novels profissionais.

## 🎯 Objetivos

Ao utilizar este material, o aluno será capaz de:

- Compreender os conceitos fundamentais de Visual Novels;
- Planejar histórias interativas com múltiplos caminhos;
- Desenvolver árvores de decisão e narrativas ramificadas;
- Criar protótipos utilizando Twine;
- Implementar Visual Novels completas utilizando Ren'Py;
- Trabalhar com personagens, cenários, diálogos, escolhas e múltiplos finais;
- Organizar projetos narrativos para publicação.

Ferramenta para criação de histórias interativas baseada em nós e conexões.

🔗 https://twinery.org/

Engine especializada no desenvolvimento de Visual Novels.

🔗 https://www.renpy.org/
